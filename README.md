# RE3: Behind the Shoulder 🧟

An independent experimental project inspired by *Resident Evil 3: Nemesis* (1999), exploring an over-the-shoulder camera, faithful 3D environments, and improved enemy AI.

Projeto experimental independente inspirado em *Resident Evil 3: Nemesis* (1999), explorando câmera sobre o ombro, cenários 3D fiéis e melhorias na IA dos inimigos.
